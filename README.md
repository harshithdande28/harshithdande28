## Featured Projects

### 🔎 Job Source Agent
`Python` `LangChain` `LangGraph` `Groq` `LinkedIn API` `Greenhouse API` `Lever API` `FastAPI`

An end-to-end agentic pipeline that takes a job search query, crawls LinkedIn listings, and extracts company/website data. Includes an LLM-driven web agent (LangGraph + Groq LLaMA 3.3) that autonomously navigates company sites and identifies career pages via tool-calling — no hardcoded rules.

### ⚙️ Automated Data Pipeline with CI/CD
`Python` `Docker` `GitHub Actions` `FastAPI` `pytest`

A containerized ML pipeline covering data preprocessing, feature engineering, model training, and evaluation. Automated unit/integration/E2E testing via pytest with commit-triggered CI/CD, cutting manual intervention by 80%. Trained models are deployed as RESTful FastAPI endpoints for real-time inference.
